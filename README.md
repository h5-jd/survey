# 聚达勘察助手 H5

珠海聚达建筑工程有限公司员工端施工管理应用

## 🚀 功能特性

### 1. 多角色权限体系 (v3.0)
- **管理员（老板）**：全局项目管理、审核验收、员工管理(创建/禁用/角色)、照片管理(全部)、系统设置
- **勘察员**：现场勘察、拍照(带水印)、AI诊断、查看自己的勘察记录和照片
- **施工员**：施工打卡(带水印拍照)、提交待验收、查看自己的施工项目和照片
- **验收员**：待验收列表、审核通过/打回、查看相关项目和照片

### 2. 水印相机 (v3.0 新增)
自动叠加水印，包含：
- 拍摄时间（YYYY-MM-DD HH:mm）
- GPS定位（经纬度）
- 员工姓名
- 项目编号/名称
- 公司名：珠海聚达建筑工程有限公司

特点：
- 自动获取GPS权限并缓存（5分钟内不重复请求）
- Canvas绘制水印，半透明白底黑字
- 水印位于照片底部，不遮挡主体
- 支持预览确认/重拍

### 3. 照片管理 (v3.0 新增)
- IndexedDB存储（容量大）
- 按项目/日期/员工分类查看
- 管理员查看全部照片
- 员工只查看自己的照片
- 照片详情：时间、位置、拍摄者、所属项目

### 4. 标准化质检节点
每一张照片就是一道质检关卡：
- **质量标准**：每个步骤明确的质量要求
- **验收要求**：可量化的验收指标
- **必拍照片**：每个步骤必须上传的现场照片
- **审核机制**：验收员/管理员审核通过后进入下一步

### 5. 施工与验收分离
```
施工员完成一步 → 水印相机拍照 → 状态变为"待验收"
                              ↓
验收员审核 → 通过✅ → 进入下一步
            → 打回❌（必须写原因）→ 施工员返工 → 重新提交
```

### 6. 账号系统升级 (v3.0)
- **关闭员工自注册**：员工账号由管理员统一创建
- **管理员创建员工**：输入姓名+手机号+选择角色
- **自动生成工号**：如 EMP0001
- **员工管理**：禁用/启用、修改角色、重置密码

### 7. PWA增强 (v3.0)
- 192x192 和 512x512 PNG图标
- 启动页/闪屏效果
- Service Worker离线缓存

## 📱 使用说明

### 首次使用
1. 打开 `pages/login.html` 进入登录页
2. 管理员默认账号：工号 `13800138000`，密码 `1234`
3. 管理员创建员工账号（姓名+手机号+角色）
4. 员工使用手机号登录（免密）

### 业务流程
1. **管理员**创建项目 → 指定勘察员/施工员/验收员
2. **勘察员**进行现场勘察 → AI诊断 → 分配工艺
3. **施工员**按步骤施工 → 水印相机拍照 → 提交待验收
4. **验收员**审核质量 → 通过/打回
5. 所有步骤审核通过 → 项目完成

## 🎯 工艺模板

### A. 外墙防水施工工艺（6步）
1. 基层清理 → 全景+手摸特写
2. 裂缝修补 → 标识+特写
3. 节点加强 → 阴角/管根/窗框节点
4. 大面涂刷 → 全景+厚度特写
5. 表层保护 → 全景
6. 闭水验收 → 蓄水+楼下检查

### B. 卫生间免砸砖施工工艺（7步）
1. 渗漏排查 → 漏点+水源
2. 微创注浆 → 孔位+过程+固化
3. 基面处理 → 缝隙+整体
4. 节点加强 → 地漏+管根+墙角
5. 大面涂刷 → 全景+厚度+渗透
6. 闭水试验 → 蓄水+楼下检查
7. 勾缝处理 → 特写+整体

### C. 窗框密封施工工艺（6步）
1. 旧胶清除 → 前后对比
2. 缝隙清理 → 特写
3. 发泡填充 → 过程+固化
4. 堵漏加强 → 涂刷特写
5. 重新密封 → 打胶+整体
6. 窗台找坡 → 全景+坡度

## v4.0 更新日志 (2024年)

### 新增9大核心功能

#### 1. 离线模式 (`js/offline-sync.js`)
- 离线数据暂存到IndexedDB，联网后自动同步
- 状态指示器显示同步状态（🟢已同步/🟡待同步/🔴离线）

- 离线存储，联网后自动转写

- 30秒短视频录制，1Mbps低码率节省空间
- Canvas实时叠加水印（时间+GPS+项目+员工）

- 管理员处理并记录结果

#### 6. 施工资料导出PDF (`js/report-export.js`)
- 使用jsPDF库生成完整施工档案
- 包含：封面/基本信息/前后对比/验收记录/异常/语音转文字/报价单/时间线/签名

#### 7. 关键节点推送 (`js/notification.js`)
- 浏览器Notification API
- 站内消息中心
- 验收请求/结果通知
- 离线队列补发

#### 8. 电子签名 (`js/signature.js`)

- 签名+时间戳组合，比纸质文件更难抵赖
